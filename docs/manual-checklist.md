# 수동 확인 체크리스트

실제 끌어 놓기는 자동 테스트로 확인할 수 없으므로 사람이 직접 확인한다. 결과 칸에 날짜와 OK/실패(이유)를 적는다.
사용법: 탐색기에서 파일을 **누른 채로** 끌다가 수정 키를 한 번 탭한다(Shift = 변환, Alt = 도구, Ctrl = 액션).

## Phase 3 — 도구 휠과 도구 창 (Task 13)

| # | 항목 | 기대 | 결과 |
|---|---|---|---|
| 21 | 이미지 1장을 끌다가 Alt 탭 | 도구 휠에 꽃잎 5개(압축·자르기·PDF 만들기·글자 복사·배경 제거; 글자 복사·배경 제거는 기능이 켜진 경우)가 뜬다 | |

| 24 | 압축 → 비율 슬라이더 70 %, 최대 크기 1280 px | 슬라이더 옆 % 값과 "예상 … 이하"가 바뀌고, 결과 긴 변이 1280 px 이하 | |

| 26 | 자르기 꽃잎 → 모서리·변 핸들, 안쪽 끌기 | 사각형이 포인터를 그대로 따라감(지연·애니메이션 없음), 이미지 밖으로 나가지 않음 | |
| 27 | 자르기 → 비율 1:1 / 16:9 / 9:16 선택 후 끌기 | 선택 즉시 그 비율로 바뀌고, 끌어도 비율 유지 | |
| 28 | 자르기 → X·Y·폭·높이에 숫자 입력(Tab으로 이동), Enter | 사각형이 숫자대로 바뀌고 비율 고정 시 반대쪽 값도 따라옴. Enter로 `이름 (cropped).확장자` 생성, 결과 크기가 입력한 폭×높이 | |
