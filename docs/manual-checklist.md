# 수동 확인 체크리스트

실제 끌어 놓기는 자동 테스트로 확인할 수 없으므로 사람이 직접 확인한다. 결과 칸에 날짜와 OK/실패(이유)를 적는다.
사용법: 탐색기에서 파일을 **누른 채로** 끌다가 수정 키를 한 번 탭한다(Shift = 변환, Alt = 도구, Ctrl = 액션).

## Phase 1 — 앱 셸과 변환 휠 (Task 6)

### 스파이크 질문 재확인 (`docs/spike-notes.md`)

| # | 항목 | 기대 | 결과 |
|---|---|---|---|
| 1 | 파일을 끌다가 마우스를 움직이지 않은 채 Shift 탭 | 휠이 바로 뜬다 | |
| 2 | 꽃잎·가운데 구멍·휠 바깥(다른 폴더 위)에 각각 놓기 | 꽃잎만 실행, 구멍·바깥은 아무 일 없음. 원본은 이동·복사되지 않음 | |
| 3 | 끄는 중 Shift/Ctrl/Alt 탭 | 탐색기 메뉴가 열리거나 드롭 효과가 바뀌지 않음 | |
| 4 | 휠이 뜬 상태에서 Esc / 왼쪽 모니터(음수 좌표)에서 시작 | Esc는 즉시 닫힘, 왼쪽 모니터에서도 휠과 드롭이 정상 | |
| 5 | 글자 선택·창 이동 드래그 중 Shift 탭 | 휠이 그려지지 않고, 버튼을 떼면 덮개가 닫혀 평소처럼 클릭 가능 | |
| 6 | 배율이 다른 모니터(예: 100% + 150%)에서 각각 시작 | 휠이 커서 모니터의 배율로 커서 위치에 뜨고, 꽃잎 판정이 그림과 맞음 | |

### 변환과 일상 동작

| # | 항목 | 기대 | 결과 |
|---|---|---|---|
| 7 | PNG 하나를 끌고 Shift → JPG 꽃잎에 놓기 | 같은 폴더에 `이름.jpg`가 생기고 진행 카드가 완료 후 4초 뒤 사라짐. 카드 클릭 시 탐색기에서 결과 선택 | |
| 8 | 이미지 3장 → 변환 휠 PDF 꽃잎 | 이미지마다 PDF가 하나씩 생긴다(3개). 여러 장을 PDF 하나로 묶는 것은 도구 휠의 'PDF 만들기'(이후 작업) | |
| 9 | 3쪽 PDF → PNG 꽃잎 | `이름 (pages)` 폴더 안에 `이름 1.png`…`이름 3.png` | |
| 10 | 휠을 띄운 뒤 바깥에 놓아 취소 | 원본이 원래 위치에 그대로 있음 | |
| 11 | 휠 없이(키 탭 없이) 평소 끌어서 이동·복사 | 평소와 똑같이 동작 | |
| 12 | 작업 관리자로 앱 강제 종료 후 평소 끌기 | 평소와 똑같이 동작(훅이 남지 않음) | |
| 13 | 드래그하지 않을 때 Shift/Ctrl/Alt를 섞어 타이핑 | 입력이 정상, 휠이 뜨지 않음 | |
| 14 | 트레이 메뉴 '휠 켜기' 체크 해제 후 끌면서 Shift 탭 | 휠이 뜨지 않음. 다시 체크하면 뜸 | |
| 15 | 변환 중 진행 카드의 '취소' | 카드가 '취소됨'으로 바뀌고 만들던 결과 파일이 남지 않음 | |
| 16 | 읽을 수 없는 파일(확장자만 .png) 변환 | 카드에 한 줄 오류, 클릭하면 닫힘 | |
| 17 | 트레이 메뉴 '윈도우 시작 시 실행', '라이선스 보기', '종료' | 각각 등록/해제, 고지 창 표시, 앱 종료(트레이 아이콘 사라짐) | |
| 18 | 앱을 두 번 실행 | 두 번째 실행은 조용히 끝나고 트레이 아이콘은 하나 | |
